# Traffic Violation SQL Analysis

## Project Overview

This project analyzes traffic violation data using SQL and MySQL to identify violation patterns, trends, and key insights from the dataset.

## Tools Used

- SQL
- MySQL
- GitHub

## Analysis Performed

- Traffic violation analysis
- State-wise violation analysis
- Violation type analysis
- Vehicle-related analysis
- Aggregation using COUNT, SUM and AVG
- Filtering and sorting data
- GROUP BY and HAVING analysis
- SQL Joins
- Business-oriented data insights

## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- LIMIT
- Aggregate Functions
- Joins

## Key Insights

The analysis helps identify patterns in traffic violations and provides insights that can support better understanding of traffic-related data.

## Project Files

- `traffic_violation_analysis.sql` — SQL queries used for the analysis.
